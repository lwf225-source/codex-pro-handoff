# 提示示例

## 仅规划

```text
$chatgpt-pro-handoff 请使用我选择并确认的普通 ChatGPT Pro 聊天，根据提供的目标和背景拆解任务，列出依赖、理由、可测试的验收标准与未知项。只规划，暂不实施。分享前先检查材料中是否有敏感信息。
```

## 仅验收

```text
$chatgpt-pro-handoff 请将我提供的现有 diff、测试输出和运行证据交给已确认的普通 Pro Chat，按标准给出 pass / revise / unknown。只验收，不做规划或修改。指出证据不足之处，不把历史回复当作本轮结果。
```

## 授权范围内的完整流程

```text
$chatgpt-pro-handoff 请在我指定的范围内让普通 ChatGPT Pro 拆解目标并定义验收标准；Codex 核对后执行授权的本地修改，再把实际 diff、测试和运行证据交回同一 Pro Chat。只针对具体失败修订，范围外建议先列出。等待并核对每轮真实回复，报告仍需外部验收的项目。
```

## 宿主能力缺失

```text
$chatgpt-pro-handoff 如果宿主没有支持普通 Chat 的直接工具，请检查是否能使用内置浏览器完成一次聊天和模型确认。若两条路径都不可用，说明缺少的能力并停止 Pro 阶段，不把 Codex 自查称为 Pro 验收。
```
